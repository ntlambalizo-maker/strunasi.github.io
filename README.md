# STRU NASI — GitHub Pages Website

This package is ready to upload to the root of the `strunasi.github.io` GitHub repository.

## Included
- `index.html`
- `styles.css`
- `script.js`
- `assets/promise-mark.png`
- `assets/promise-mark-lockup.png`

The website uses the official STRU NASI Promise Mark artwork supplied in the brand guidelines as the logo asset rather than a placeholder icon.

## GitHub Pages
1. Upload all files and the `assets` folder to the repository root.
2. Commit the changes.
3. Go to Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main` and folder `/ (root)`.
6. Save.

## Before launch
Replace the placeholder WhatsApp number, Instagram, Facebook and email links in `index.html` with the real STRU NASI details.
