# STRU NASI Website

Launch-ready static website files for **STRU NASI — The Promise You Wear**.

## Included pages
- `index.html` — Home
- `shop.html` — Shop
- `story.html` — Our Story
- `campaign.html` — Campaign 001
- `contact.html` — Contact
- `styles.css` — Site styling
- `script.js` — Loader + mobile nav
- `assets/images/` — Brand and campaign images

## Quick start
1. Upload all files to your GitHub repository.
2. Keep the folder structure exactly the same.
3. If you are using GitHub Pages:
   - Go to **Settings → Pages**
   - Set the source to the main branch (root)
   - Save
4. Your site will publish from the repo root.
