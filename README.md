# STRU NASI — Free Website

This is a static, mobile-friendly STRU NASI launch website.

## Files
- `index.html` — website structure and content
- `styles.css` — design and responsive layout
- `script.js` — mobile menu

## Before publishing
1. Replace the placeholder WhatsApp links with the real STRU NASI WhatsApp number.
2. Replace Instagram/Facebook links with the real accounts.
3. Replace `hello@strunasi.co.za` with the email address you actually use.
4. Replace the R499 placeholder prices with your final prices.
5. Replace the visual placeholders with your actual STRU NASI product/campaign photos.

## Free hosting
The site can be published free with GitHub Pages. Upload these three website files (`index.html`, `styles.css`, `script.js`) to a GitHub repository and enable Pages in the repository settings.

A custom `strunasi.co.za` domain can be connected later.
