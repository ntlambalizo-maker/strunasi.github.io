# STRU NASI — GitHub Pages Website

A static, ready-to-upload STRU NASI website built around the official Promise Mark supplied for the brand.

## Pages
- `index.html` — Home
- `shop.html` — Shop / collection filters
- `product.html` — Product detail
- `about.html` — About / story
- `contact.html` — Contact

## Upload to GitHub Pages
1. Create a GitHub repository (for example `strunasi.github.io`).
2. Upload **all files and folders inside this ZIP** to the repository root.
3. Go to **Settings → Pages**.
4. Set the source to **Deploy from a branch**, choose `main`, folder `/ (root)`, and save.
5. GitHub Pages will publish the site.

No build step, Node.js, database, or paid hosting is required for this static version.
