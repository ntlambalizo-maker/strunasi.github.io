# STRU NASI website

Ready-to-upload static website for GitHub Pages.

## Files
- index.html — home / hero / categories / Promise Mark / best sellers
- shop.html — product grid with Tees / Hoodies
- story.html — brand story
- campaign.html — Campaign 001
- contact.html — WhatsApp / Instagram / Facebook / email
- style.css — black luxury theme using #080808 and #D8C3A0
- script.js — filters + mobile menu
- assets/hero.jpg — STRU NASI campaign banner
- assets/promise-mark.svg — Promise Mark

## GitHub Pages
Upload all files/folders inside this package to the root of your `strunasi.github.io` repository. Do not upload the ZIP itself.

## Before launch
Replace the placeholder WhatsApp number, social links and email with your real details.
